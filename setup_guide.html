Local Reader · setup guide

Get the chikari.moe local reader running

Adds a Play button to chikari.moe chapters that reads them aloud with a local voice engine.

Runs on your PC Nothing leaves your machine No account, free voices

Before you start

  • Windows 10 or 11. The installer and server are Windows-only for now.
  • ~400 MB free disk space for the voice engine, downloaded once during setup.
  • Google Chrome (or another Chromium browser that supports unpacked extensions, like Edge or Brave).
  • 5–10 minutes, mostly the download.

Installing

Unzip chikari-local-reader-package.zip, then do these in order.

1

Run the setup script

Double-click Install.bat. Installs Python if it's missing and downloads the voice model (~350 MB). Wait for All done!

2

Load the extension

Go to chrome://extensions, enable Developer mode, click Load unpacked, and select the extension folder.

3

Start the server

Double-click Start Server.bat. No window opens — look for its icon in the system tray instead. Right-click it and choose Close Server when you're done reading.

4

Play a chapter

Open any chapter on chikari.moe and hit Play in the panel, bottom-right.

Every time after that

Setup is one-time. From now on, reading just takes two steps:

  • Double-click Start Server.bat (it runs quietly in the system tray).
  • Open a chapter on chikari.moe and press Play in the panel.

Choosing a voice

Click the ⋮ button in the panel to pick a voice (Michael, Bella, George, Emma, Puck, or Nova) and playback speed. Changing either restarts synthesis for the current chapter with the new setting.

If something's not working

Avoid refreshing or closing the page while synthesis is running

Chunks already in progress can't be stopped mid-flight, only queued ones. Refresh anyway and the next attempt may sit at 0% for up to a minute while those leftover chunks finish in the background — it'll recover on its own, just wait it out rather than restarting the server.

Panel missing, or status says the server is unreachable

Check the system tray for the Local Reader icon — if it's not there, double-click Start Server.bat again. If the panel itself is missing, refresh the page and check the extension is switched on at chrome://extensions.

Windows warns about Install.bat or Start Server.bat

Normal for scripts that aren't from the Microsoft Store. Click "More info" → "Run anyway."

Voice synthesis runs locally. Nothing is uploaded.
